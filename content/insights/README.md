# Insights content

Each article is one Markdown file in this folder, named by its URL slug
(`how-to-scope-an-mvp.md` → `/insights/how-to-scope-an-mvp`).

1. Copy `_template.md` to `<slug>.md` and fill in the front matter.
2. Write the article in Markdown (`##` / `###` headings, lists, quotes, code).
3. Keep `status: draft` while writing and reviewing.
4. Set `status: approved` only after review. Approved articles appear on
   `/insights`, in the sitemap and — once at least one exists — in the
   main navigation.

Suggested first topics (pending original writing) are listed in
`content/insight-topics.ts`. Never publish placeholder or generated text.
